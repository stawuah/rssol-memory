# Week 06 Mini-Project

Project: `replica-coordinator`

## Build target

Create a service that:

- accepts tasks
- dispatches them to worker replicas
- waits for responses
- applies timeouts or retries
- reports queue health

## Interactive prompts

- What state is global?
- What state belongs to each worker?
- Which failures are recoverable?
- What metric would reveal backpressure?

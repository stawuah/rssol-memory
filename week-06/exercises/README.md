# Week 06 Exercises

Theme: concurrency, channels, and async foundations.

## Interactive exercise set

### ex01-worker-pool

Build a small thread-based worker pool.

### ex02-channel-coordinator

Send tasks from a coordinator to workers through channels.

### ex03-timeout-simulation

Simulate requests that succeed, stall, or time out.

### ex04-backpressure-observer

Measure what happens when producers outpace consumers.

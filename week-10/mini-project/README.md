# Week 10 Mini-Project

Project: `vault-program`

## Build target

Build a vault or treasury-style program with:

- deposit and withdraw flows
- authority controls
- PDA-based rules where appropriate
- tests for invalid callers
- a short written threat model

## Interactive prompts

- Who controls funds?
- Which inputs are untrusted?
- What must always be true before tokens move?
- What is the most expensive bug you could introduce here?

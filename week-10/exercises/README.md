# Week 10 Exercises

Theme: CPIs, tokens, security, and negative testing.

## Interactive exercise set

### ex01-cpi-call-path

Trace what must be validated before performing a CPI.

### ex02-owner-signer-checks

Given mock accounts, distinguish owner-check failures from signer-check failures.

### ex03-vulnerability-patch

Start from a deliberately weak instruction design and identify the bug.

### ex04-negative-tests

Write tests that prove unauthorized mutation fails.

## Questions to answer

- Why is a CPI boundary dangerous?
- Why are owner checks and signer checks not interchangeable?
- What does stale state mean in practice?
- Why should security tests include failure cases first?

# Week 08 Mini-Project

Project: `solana-native-hello-state`

## Build target

Create a native Rust Solana program that:

- stores small state in an account
- validates signer and ownership assumptions
- updates state deterministically
- includes tests for at least one failure mode

## Interactive prompts

- What state lives in the account?
- Who is allowed to mutate it?
- What checks happen before state changes?
- How does this resemble the state machines from earlier weeks?

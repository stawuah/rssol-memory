# Week 08 Interactive Guide

## Big idea

This week is the bridge from Rust systems thinking into Solana.

## Explain like I'm five

Solana is like a shared notebook system where everyone can watch, but updates only happen through very strict forms.

## Distributed systems from scratch

A Solana program is a deterministic state transition function.
Given the same accounts and instruction data, it should produce the same result.

## Solana-from-scratch checkpoints

- What is an account?
- Why does Solana separate program code from account data?
- Why must transactions declare accounts up front?
- What is a PDA in plain language?
- How is this related to authority and safe mutation?

# Week 08 Exercises

Theme: Solana foundations and native Rust programs.

## Interactive exercise set

### ex01-instruction-bytes

Decode simple instruction byte layouts manually.

### ex02-pda-derivation

Derive PDAs from seed combinations and explain why deterministic addresses matter.

### ex03-account-validator

Given mock account metadata, reject invalid ownership, signer, or size conditions.

### ex04-transaction-trace

Write a narrative trace of how a Solana transaction moves through validation and execution.

## Questions to answer

- What is an account?
- Why does Solana declare account access up front?
- How does this help parallel execution?
- Why are Solana programs deterministic state machines?

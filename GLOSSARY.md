# Repository Glossary

This is the top-level glossary entry point for the repository.

Use it when you hit a term that slows you down in any of the three tracks:
`rustlings-core`, `anchor-core`, or `protocol-core`.

The canonical long-form glossary for the protocol engineering material lives
here:

- [Protocol Core Glossary](./protocol-core/GLOSSARY.md)

The protocol glossary covers the full Rust, Solana, Anchor, DeFi, MEV,
governance, security, and zero-knowledge vocabulary used throughout the repo.
If you are studying the earlier tracks, this file is still a good starting point
because many of the same terms appear there in simpler form.

If you want a compact study path, read the relevant module README first, then
come back here when a term or concept needs a plain-language definition.

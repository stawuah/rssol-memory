# Mastery Rubric

Use this to grade yourself honestly.

## Level 0: Exposure

- I have seen the concept before
- I cannot implement it without heavy help

## Level 1: Assisted use

- I can complete the exercise with hints
- I can explain the happy path only

## Level 2: Independent use

- I can solve the exercise without copying
- I can explain the key failure mode
- I can modify the code safely

## Level 3: Transfer

- I can apply the same concept in a new project
- I can explain where it appears in Solana or distributed systems
- I can review someone else’s code using that concept

## Level 4: Interview ready

- I can explain the idea clearly under pressure
- I can compare tradeoffs
- I can defend one design choice over another

## Weekly promotion rule

Do not advance a week as "mastered" unless:

- all exercises are solved
- the mini-project works
- you can answer the interactive checkpoints
- at least half the core concepts feel like Level 2 or better

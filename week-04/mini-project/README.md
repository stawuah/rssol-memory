# Week 04 Mini-Project

Project: `distributed-kv-core`

## Build target

Create a reusable library that:

- stores key-value state
- applies typed commands
- validates transitions
- supports at least one trait-based storage backend
- includes strong tests

## Interactive prompts

- What behavior is generic?
- What invariant must every backend preserve?
- How would you mock storage in a larger distributed system?

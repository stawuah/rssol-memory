# Week 01 Exercises

Run each exercise independently:

```bash
cargo test -p ex01-temperature-converter
cargo test -p ex02-fibonacci
cargo test -p ex03-cli-calculator
cargo test -p ex04-retry-loop
```

Rules:

- fill in the `todo!()` sections
- do not remove tests
- prefer small, explicit functions
- after tests pass, run `cargo clippy --all-targets --all-features`

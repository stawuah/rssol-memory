# Week 05 Mini-Project

Project: `membership-registry`

## Build target

Create a registry that:

- tracks node membership
- records last update time or tick
- supports shared reads
- supports safe mutation
- avoids unnecessary cloning

## Interactive prompts

- Which fields are owned?
- Which data could be borrowed?
- What synchronization primitive is justified here?
- What would the simplest correct version look like?

# Week 11 Exercises

Theme: clients, indexers, and eventual consistency.

## Interactive exercise set

### ex01-cli-client

Build a client that constructs or simulates program instructions.

### ex02-event-consumer

Consume emitted events or mocked event records into a read model.

### ex03-lagging-indexer

Simulate an indexer that falls behind and later catches up.

### ex04-cache-recovery

Recover a query cache after missed events.

## Questions to answer

- Why are on-chain state and app views different concerns?
- What is eventual consistency?
- What happens when an indexer misses data?
- Where should truth live?

# Exercises

Every exercise folder contains its own `README.md`. Read it first, then follow
the numbered guidance beside each `todo!()` in `src/lib.rs`.

The point is not to memorize Solana jargon.
The point is to feel how the state machine works.

## Before you code

- What is public?
- What is private?
- What is derived?
- What is authorized?
- What can the runtime verify?

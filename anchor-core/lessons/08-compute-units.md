# 08 Compute Units

## Analogy

Compute units are the fuel gauge for an instruction.

If you overrun the budget, the transaction fails.

## Official facts

Solana says each transaction pays fees, has a base fee, and may also include a prioritization fee.
The fees page lists a default instruction compute unit limit of 200,000 and a max transaction limit of 1,400,000.

- [Solana Fees](https://solana.com/docs/core/fees)

# 10 OSS Contribution

## Analogy

Open source is a shared workshop.

You do not start by rebuilding the whole machine.
You start by understanding one part, one test, one invariant.

## What to practice

- read the docs before the code
- find the smallest crate or module that matches the bug
- reproduce the failure locally
- fix one thing
- add one test
- explain the behavior in the PR

## Good first contributions

- docs fixes
- test improvements
- clearer error messages
- small account validation improvements
- examples that explain the macro or layout better

## Exercise

Pick one exercise in `anchor-core` and answer:

1. What would a contributor need to understand before changing this?
2. What test would protect the behavior?
3. What is the smallest safe change?

# Week 07 Exercises

Theme: serialization, persistence, and recovery.

## Interactive exercise set

### ex01-serialize-node-state

Serialize node state to JSON and deserialize it back.

### ex02-binary-message-format

Design a compact binary message format for a few message types.

### ex03-append-only-log

Append events to a file in order.

### ex04-recovery-replay

Load a persisted log and rebuild in-memory state.

## Questions to answer

- Why does persistence matter?
- What does replay mean?
- Why might binary formats beat JSON?
- What corruption or truncation cases should you think about?
